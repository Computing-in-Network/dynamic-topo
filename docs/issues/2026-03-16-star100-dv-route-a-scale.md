# star100 Route A DV 原型扩展与规模验证

## 背景

当前仓库已经完成：

- `10` 节点 Route A DV 原型
- `50` 节点 Route A DV 稳定性验证

在 `50` 节点连续稳定运行的基础上，需要继续扩展到 `100` 节点，验证当前 DV 原型在更大规模下的可收敛性和基本稳定性边界。

## 目标

1. 将现有 Route A DV 原型扩展到 `100` 节点
2. 继续复用已有参数化启动流程，避免复制整套控制脚本
3. 完成 `100` 节点场景的启动、收敛和端到端可达性验证

## 范围

1. 新增 `100` 节点启动/停止入口
   - `start_star100_dv_route_a.sh`
   - `stop_star100_dv_route_a.sh`

2. 文档补充
   - README 增加 `100` 节点启动和检查方式

3. 运行验证
   - `100` 个 agent 全部启动成功
   - 抽样节点能学到 `99` 条 `/32` 路由
   - 抽样两点间能够直接 `ping 10.255.x.x`

## 验收标准

1. 能通过单条命令启动 `100` 节点 Route A DV 原型
2. `manage_dv_agents.py --action status` 能看到 `100` 个 agent 进程
3. 抽样节点路由表包含 `99` 条 DV `/32` 目标
4. 抽样 `node1 -> node100` 端到端连通成功

## 注意事项

1. `100` 节点场景不能与 `300` 节点静态控制面并行运行
2. `100` 节点场景需要与 `10/50` 节点运行目录和日志隔离
3. 若规模继续扩大到 `150/300`，可能需要进一步优化 DV 报文编码与更新抑制
